# Day 1 summary — Ship by Thursday / pop-up OS

**Date:** 2026-09-15 · **Duration:** ~8.75 h · **Broadcast:** https://x.com/i/broadcasts/1AxRnZbVpjaxl

## What happened

Matt Palmer, Lauren Tan, and Roshan Sadanani kicked off a 72-hour “build a real company with Grok Bot” stream. They started from a blank **Ship by Thursday** GitHub org, Slack as control plane, and empty Grok Bot accounts. Early tooling bets: Slack, Notion, P-Stack (Lauren’s marketplace eng pack), X MCP for idea mining.

**Grok Bot 101 (Roman Ugarte)** demonstrated multi-bot collaboration with **Data Dan**, **Slide Sonia**, and **Email Ethan**; **teach a task** (screen demo → skill); auto-review approval gates; and long-lived **S3 memory**.

On the build spine, Lauren installed marketplace **Dr. Eggbot**, renamed her default bot **Steve**, and had Eggbot promote Steve to **Chief of Staff**. Chat named prototyper **Grokpot**. Thesis crystallized around a **pop-up OS** for restaurants. Steve opened an unread **~2000-line PR**, prompting the rule: **no PRs — ship to main**. Domain **shipbythurs.day** acquired; HTML prototypes deployed via **Vercel**. Food-themed eng bots **Tater** + reviewer **Hashbrown** and a **Knowledge Base Manager** (Notion) appeared.

**Engineering (Lingxi Li)** covered agent factories and Slack PR automations. **PMs (Kevin Niparko)** showed squad **Cora, Emily, Ashley, PM Pete, Pixel, Ray**. **Founders (Shub Gaur)** featured guest Jenny’s **CloseBot / ProdBot / StockBot / YapBot**, plus anecdote **Master Chief** CoS.

## Outcomes

- Company identity: Ship by Thursday; blank → landing HTML on Vercel  
- Bot org pattern: CoS + meta-bot + specialists  
- Explicit process: Slack control plane, ship-to-main, teach-a-task, auto-review, S3 memory
